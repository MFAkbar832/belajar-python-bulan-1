# 🛒 Aplikasi Kasir Mini (CLI)

Aplikasi kasir berbasis konsol (*Command Line Interface*) sederhana yang dibangun menggunakan bahasa pemrograman **Python**. Proyek ini merupakan **Solo Project Akhir Bulan ke-1** sebagai implementasi fondasi logika pemrograman dan struktur data dasar.

## ✨ Fitur Utama
- **Tambah Item Belanja:** Mencatat nama barang, harga satuan, dan jumlah pembelian secara dinamis.
- **Kalkulasi Otomatis:** Menghitung subtotal per item dan total keseluruhan tagihan secara real-time.
- **Proses Pembayaran & Struk:** Validasi pembayaran uang tunai, perhitungan kembalian otomatis, dan cetak struk transaksi.
- **Reset Transaksi:** Mengosongkan keranjang belanja secara otomatis setelah pembayaran lunas untuk melayani pelanggan berikutnya.

## 🧠 Konsep Pemrograman yang Diterapkan
- Variabel & Tipe Data (`String`, `Integer`)
- Operator Matematika & Perbandingan
- Logika Percabangan (`if`, `elif`, `else`)
- Pengulangan (`for` loop & `while` loop)
- Struktur Data List / Array & Manipulasinya (`.append()`, `.clear()`, `len()`)
- Modularisasi Kode menggunakan Fungsi (`def`, *parameters*, dan `return` statement)

## 🚀 Cara Menjalankan Program
1. Pastikan **Python** sudah terinstal di komputer Anda.
2. Clone repositori ini atau unduh file `kasir.py`.
3. Buka terminal di folder proyek, lalu jalankan perintah:
   ```bash
   python kasir.py
   ```
